# Research notes

## Hermes reference

The Hermes Agent landing page was reviewed as a reference for principles, not
as a visual source to copy. Its useful moves are:

- a very large promise before detail;
- numbered capability progression that creates a reading rhythm;
- short headlines followed by concise explanations;
- a clear distinction between product surface and supporting detail;
- repeated, visible calls to action;
- a feeling of one coherent product rather than a collection of pages.

The page also uses a strong marketing narrative: promise, capability proof,
operational breadth and conversion. Those mechanics are reusable; its brand,
illustration language, copy, palette and composition are not.

## NOVA Abme response

NOVA Abme translates those principles into a different identity:

| Principle | NOVA Abme decision |
|---|---|
| Hierarchy | Oversized editorial type, small technical labels and a single route per block |
| Scale | Hero dominates; supporting data stays compact and scan-friendly |
| Storytelling | Impact → context router → stack map → public proof → lab → business → connect |
| Negative space | Long section intervals and a restrained grid expose the content instead of filling it |
| Microinteraction | CSS hover/focus states, native observer reveals, context panel and command palette |
| Progression | `BUILD / CONNECT / CREATE / SHIP` gives the scroll a four-beat backbone |
| Conversion | GitHub, ELP Tecnologia and direct contact routes are visible before and after proof |
| Product feeling | `NOVA ABME / PROFILE 001` frames the page as a profile surface in a future platform |

## Visual direction

The design uses the required **Ink Wash** base:

- background `#252525`;
- primary text `#CFCFCF`;
- secondary/muted `#7D7D7D`;
- UI/borders `#545454`.

`#A7A7A7` and `#E4E4E4` are conservative derived tones used only when the
base secondary tone would not meet small-text contrast or a selected control
needs a clear state. There are no technology-color badges, neon effects,
particles, stock photography or decorative gradients.

## Content boundary

Public GitHub profile and public repositories were used to verify the visible
identity, public links and selected work. Corporate systems and NOVA internal
architecture are intentionally not described in this repository. The page
mentions VANTA Labz as the open-source/lab surface without inventing a private
project URL or exposing non-public implementation details.
